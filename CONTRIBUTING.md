# Como contribuir com o JADÁ

Que bom que você quer ajudar! 💚 O JADÁ é feito para a comunidade, e a comunidade é a melhor fonte de ideias, testes e correções.

> **Importante:** este repositório é a **vitrine** do projeto. O código-fonte do aplicativo é **privado** e não está aqui.
> Mesmo assim, quase toda contribuição pode ser feita por **issues** e **discussões**, e documentação e imagens aceitam **pull requests** neste repositório.

🌐 O app está no ar em **[jadabrasil.com.br](https://jadabrasil.com.br/)**: use-o para testar, encontrar bugs e sugerir melhorias.

Ao participar, você concorda em seguir o nosso [Código de Conduta](CODE_OF_CONDUCT.md).

---

## Formas de contribuir

### 🐞 1. Reportar bugs
Encontrou algo quebrado, lento ou estranho? Abra uma issue com o modelo **Bug**.
- Diga **onde** aconteceu (página, por exemplo `/mapa` ou a página de um local) e **o que** você esperava.
- Informe aparelho, sistema e navegador (ex.: *iPhone 13, iOS 18, Safari*).
- Se puder, anexe um print ou um vídeo curto.
- Veja antes se já não existe uma issue igual. Se existir, deixe um 👍 e complemente nos comentários.

### 💡 2. Sugerir funcionalidades
Use o modelo **Sugestão de funcionalidade**. Explique primeiro o **problema** que você quer resolver e só depois a ideia de solução. Lembre que o JADÁ é **apartidário**: sugestões com conteúdo político (candidatos, partidos, pesquisas, intenção de voto) não serão aceitas.

### 🎨 3. Feedback de UX, design e acessibilidade
Achou um texto confuso, um botão difícil de tocar, contraste baixo ou algo ruim no leitor de tela? Abra uma issue com o rótulo `ux` ou `acessibilidade`. Prints com anotações ajudam muito.

### 📍 4. Correção de dados de locais de votação
A base vem dos dados abertos do TSE, mas pode ter endereço desatualizado, coordenada errada no mapa ou nome escrito de outro jeito. Use o modelo **Correção de dados de local de votação** e informe:
- UF, município, zona e número do local (ou o link da página do local no JADÁ);
- o que está errado e qual é a informação correta;
- uma fonte, se tiver (site da prefeitura, foto da fachada, Google Maps etc.).

> Nunca envie dados pessoais seus ou de outras pessoas (título de eleitor, CPF, foto de documento).

### 🌎 5. Traduções e textos
A interface é em português, mas queremos um resumo em inglês e espanhol para imprensa e pesquisadores. Revisão de textos em pt-BR (clareza, tom, erros) também é bem-vinda. Abra uma issue com o rótulo `traducao`.

### 📝 6. Documentação e mídia (pull requests)
Este repositório aceita PRs com:
- correções e melhorias no README, ROADMAP e nos demais documentos;
- novas capturas de tela ou vídeos (sempre com **dados fictícios**, nunca com dados reais de pessoas);
- melhorias nos modelos de issue.

Fluxo: faça um fork → crie um branch (`docs/minha-melhoria`) → faça o commit → abra o PR preenchendo o modelo.

## 👩‍💻 Quero contribuir com código

O código-fonte é privado neste momento, mas colaborações são bem-vindas. Para pedir acesso:

1. Abra uma issue com o título **"Pedido de acesso ao código"** (ou inicie uma discussão, se elas estiverem ativas).
2. Conte brevemente sua experiência (front-end React/TypeScript, back-end .NET, MongoDB, dados, design, testes...) e **no que** gostaria de ajudar (pode ser uma issue já aberta).
3. Se fizer sentido para o momento do projeto, o mantenedor entra em contato para combinar os próximos passos (acesso ao repositório privado e, se preciso, um termo simples de colaboração).

Não há garantia de acesso, mas toda proposta é lida.

## 🏷️ Rótulos (labels)

| Rótulo | Uso |
|---|---|
| `bug` | Algo não funciona como deveria |
| `melhoria` | Sugestão de funcionalidade ou de melhoria |
| `ux` | Experiência de uso, textos e fluxo |
| `design` | Visual, identidade e layout |
| `acessibilidade` | Leitores de tela, contraste, teclado, tamanho de toque |
| `dados` | Correções na base de locais de votação |
| `traducao` | Traduções e revisão de textos |
| `documentacao` | README e demais documentos deste repositório |
| `mobile` | Problemas específicos de celular |
| `boa primeira issue` | Ótima para começar |
| `ajuda bem-vinda` | Queremos ajuda da comunidade nisso |
| `pedido de acesso` | Pedido para colaborar com o código privado |
| `duplicada` / `nao-sera-feito` | Triagem |

## 🌱 Ideias de "boa primeira issue"

- Revisar os textos da página **Como funciona** e sugerir uma linguagem mais simples.
- Testar o app no seu celular e relatar o que achou estranho (com print).
- Conferir no mapa os locais da sua cidade e reportar coordenadas erradas.
- Traduzir o resumo do README para espanhol.
- Sugerir um texto de ajuda para quem nunca usou o app (primeiro acesso).
- Fazer uma revisão de acessibilidade (contraste e leitor de tela) de uma página.
- Propor ícones ou ilustrações para os estados da fila.

## ⏱️ O que esperar

- Issues são triadas, em geral, em até uma semana.
- Nem toda sugestão entra no produto. Quando não entrar, explicamos o motivo.
- Contribuições aceitas são creditadas no changelog/README (se você quiser).

Obrigado por ajudar mais gente a votar sem perder tempo na fila! 🗳️
